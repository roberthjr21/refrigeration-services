ESTADO DE VERIFICACIÓN DE POSTGRESQL
No se pudo descargar pg ni @types/pg desde este entorno: npm install devuelve EACCES al acceder a registry.npmjs.org. package.json ya declara ambas dependencias, pero package-lock.json aún requiere actualización en un terminal con acceso al registro. Por eso, después del cambio, lint pasa pero tsc y build fallan con “Cannot find module 'pg'”.

Tampoco hay psql/PostgreSQL local ni DATABASE_URL configurada en este entorno. La conexión real y la ejecución de db/schema.sql quedan pendientes de instalar dependencias, colocar una URL de conexión en .env.local y correr npm run db:setup.
